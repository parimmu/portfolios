# Prim Wanaprapa — Portfolio

A single-page portfolio site. No build step, no framework — plain HTML/CSS/JS.

## Structure

```
index.html        — page structure/content
css/style.css      — all styling
js/main.js         — scroll progress bar, nav highlighting, page counter,
                      card-fan interactions, Na Navee gallery
assets/            — images + downloadable resume PDF
```

## Running locally

Just open `index.html` in a browser — no server or build step required.

## Deploying

Push this whole folder (with `assets/` intact) to a GitHub repo, then enable
GitHub Pages in Settings → Pages → Deploy from branch → main → / (root).
